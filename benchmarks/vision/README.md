# Vision / Screenshots

This suite measures practical screenshot analysis and external multimodal references through Ollama vision input.

Practical tests cover technical diagnosis, layout defects, screenshot/code synthesis, OCR, GUI grounding, diagram interpretation, and epistemic restraint. Quick runs V1/V4/V5/V7 once, standard runs V1-V7 three times, and full runs V1-V7 five times.

The external layer uses ScreenSpot click accuracy and MMMU-Pro multiple-choice accuracy. Quick and standard use deterministic subsets; full uses the complete prepared sets. Dataset revisions, selected IDs, images, ground truth, model output, reasoning, timing, and power evidence are retained.

Published Instruct and Thinking weights are treated as separate model identities. Hybrid reasoning modes are also separate configurations.
